## [1.0.0](https://github.com/elct9620/auto-renamer/compare/auto-renamer-v0.1.0...auto-renamer-v1.0.0) (2026-10-02)


### ⚠ BREAKING CHANGES

* **config:** `watch.target`, `pipelines`, and the `move` and `cleanup` stages are gone; declare `[target.<name>] path = "..."` and `routes = [{ pipeline = "...", move = "<name>", cleanup = { keep = [...] } }]`.
* **config:** configurations must use `quiet`, `max_wait` and `max_files`; the `batch_*` keys are refused as unknown.
